### Corrections

- 2.0.0 incorrectly raised the minimum supported Python version to 3.12. This release restores `requires-python = ">=3.11"` so `arches-vue-components` can actually be installed by the Arches 8.0.x/8.1.x users it claims to support. [#12](https://github.com/archesproject/arches-vue-components/pull/12)


### Upgrading Arches Vue Components

1. Upgrade the python package:
    ```
    pip install --upgrade arches-vue-components==2.0.2
    ```

No further action is required — this release only corrects the Python version floor and related metadata.
