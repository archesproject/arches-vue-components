# Arches Vue Components 2.2.0 Release Notes

### Breaking changes

- Arches 8.2.0 is now the minimum Arches version [#37](https://github.com/archesproject/arches-vue-components/pull/37)
- Widgets now participate in a `ready` event contract. `GenericWidget` declares a `ready: []` emit, and widget components are expected to emit `ready` once they are actually usable. This is distinct from the existing `initialized` event, which fires immediately and only means "has an initial value." Custom widgets outside this repository that do not emit `ready` will leave consumers waiting on readiness indefinitely [#42](https://github.com/archesproject/arches-vue-components/pull/42)
- The map-drawing internals moved from `arches_vue_components/widgets/MapWidget/` to `arches_vue_components/components/MapComponent/`. Deep imports into the old paths must be repointed [#42](https://github.com/archesproject/arches-vue-components/pull/42)
- The `Basemap`, `MapLayer`, and `MapSource` types are no longer re-exported from `arches_vue_components/widgets`; they are now exported from `arches_vue_components/components` [#42](https://github.com/archesproject/arches-vue-components/pull/42)

### New Features

- Extract the map-drawing engine out of `MapWidget` into a standalone `MapComponent`, usable independently of the resource-editing system [#42](https://github.com/archesproject/arches-vue-components/pull/42)
- `GeometryTypeConfig`, `MapCardXNodeXWidgetData`, and `MapWidgetConfig` are now exported from `arches_vue_components/widgets` [#42](https://github.com/archesproject/arches-vue-components/pull/42)

### Bug Fixes

- Fixes file uploads on cardinality-N file-list widgets: files are now submitted with tile-scoped form field names (`file-list_<tileid>-<nodeid>`) instead of node-scoped ones (`file-list_<nodeid>`), so each file reaches the correct tile when saving multiple new cardinality-N tiles at once. Previously released on the 2.0 line in 2.0.3 [#34](https://github.com/archesproject/arches-vue-components/pull/34)

### Upgrading Arches Vue Components

1. Upgrade the python package:

    ```bash
    pip install --upgrade arches-vue-components==2.2.0
    ```

1. Rebuild your frontend bundle:

    - If you plan on doing active development, and need to see frontend changes automatically, run:

        ```bash
        npm start
        ```

    - If you do not plan to do active development, run:

        ```bash
        npm run build_development
        ```

    - if you are running in production, collect your static files:

        ```bash
        python manage.py collectstatic
        ```

1. If you are running Arches on Apache, restart your server:

    ```bash
    sudo service apache2 reload
    ```
