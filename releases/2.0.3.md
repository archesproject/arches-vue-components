### Bug Fixes

- Fixes file uploads on cardinality-N file-list widgets: files are now submitted with tile-scoped form field names (`file-list_<tileid>-<nodeid>`) instead of node-scoped ones (`file-list_<nodeid>`), so each file reaches the correct tile when saving multiple new cardinality-N tiles at once. [#34](https://github.com/archesproject/arches-vue-components/pull/34)

### Upgrading Arches Vue Components

1. Upgrade the python package:
    ```
    pip install --upgrade arches-vue-components==2.0.3
    ```

2. Rebuild your frontend bundle to pick up the updated file-upload widget source:
    ```
    npm run build_development
    python manage.py collectstatic
    ```

3. If you are running Arches on Apache, restart your server:
    ```
    sudo service apache2 reload
    ```
