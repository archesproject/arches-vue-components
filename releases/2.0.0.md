> **Correction (2.0.2):** The "Requires Python 3.12+" and "Targets 8.2.x only" claims below were incorrect. `arches-vue-components` 2.0.x supports Arches 8.0.x/8.1.x on Python 3.11+; see [2.0.2 Release Notes](2.0.2.md).

### Breaking Changes

- Drops support for Arches < 8.0. Targets 8.2.x only. [#12](https://github.com/archesproject/arches-vue-components/pull/12)
- Requires Python 3.12+. [#12](https://github.com/archesproject/arches-vue-components/pull/12)
- `pgtrigger` is required in `INSTALLED_APPS` again. [#12](https://github.com/archesproject/arches-vue-components/pull/12)
- Removes the Arches-version checks in `CardXNodeXWidgetView`, `RelatableResourcesView`, and `CardNodeWidgetConfigMixin` — they now assume Arches 8.x model semantics. [#12](https://github.com/archesproject/arches-vue-components/pull/12)
- Widgets go back to `defineProps<T>()`/`defineEmits<T>()` generics instead of the cast-pattern workaround from 1.0. [#12](https://github.com/archesproject/arches-vue-components/pull/12)

### Bug Fixes

- Patches `vue/compiler-sfc` to resolve prop types from an in-memory tsconfig, fixing the pip-install breakage that forced the cast-pattern workaround in 1.0. [#12](https://github.com/archesproject/arches-vue-components/pull/12)
- Restores the `language-widget` mapping migration via a new `0006_add_language_widget_mapping`. [#12](https://github.com/archesproject/arches-vue-components/pull/12)
- Updates the webpack build to Arches 8.2's patterns — deterministic chunk IDs, a dedicated runtime chunk, asset-module loaders for fonts/HTML/text. [#12](https://github.com/archesproject/arches-vue-components/pull/12)
- Updates CI to Python 3.12–3.14, PostGIS 14-3.4, and PEP 735 dependency groups. [#12](https://github.com/archesproject/arches-vue-components/pull/12)
- Adds monthly Dependabot updates for npm.

### Upgrading Arches Vue Components

1. Upgrade the python package:
    ```
    pip install --upgrade arches-vue-components==2.0.0
    ```

2. Ensure `pgtrigger` is listed in your project's `INSTALLED_APPS` alongside `arches_querysets` and `arches_vue_components`:
    ```python
    INSTALLED_APPS = (
        "my_project_name",
        ...
        "arches_querysets",
        "arches_vue_components",
        "arches",
        ...
        "pgtrigger",
    )
    ```

3. Update the frontend dependency in `package.json` and reinstall:
    ```
    npm install
    npm run build_development
    python manage.py collectstatic
    ```

4. If you are running Arches on Apache, restart your server:
    ```
    sudo service apache2 reload
    ```
